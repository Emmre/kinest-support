# Kinest public pages

This directory contains the unpublished, static pages intended for a separate public GitHub Pages repository.

Before publishing:

1. Copy `index.html`, `privacy.html`, and `support.html` into a small public repository.
2. Confirm the support email `emreesrc@gmail.com` and publisher/legal identity text before publication.
3. Enable GitHub Pages for the repository's default branch.
4. Open both generated HTTPS URLs in a private browser window.
5. Add `https://emmre.github.io/kinest-support/privacy.html` and `https://emmre.github.io/kinest-support/support.html` to the final release metadata after both URLs are live and verified.

The prepared contact is `emreesrc@gmail.com`. Do not publish until the page URLs have been verified after enabling GitHub Pages.
