How to open local videos on iPhone

  1. Save a compatible MP4, MOV or M4V video in the Files app or another supported file location.
  2. Launch Kinest. If your library is empty, tap Open Video.
  3. Choose the video using the iOS file picker. It plays without being added to your Library.
  4. You can also use the Open In or Share action for a compatible video in Files to open it with Kinest, when available.

Locally available videos can play offline. Cloud files might need to download first. Playback support depends on the iOS-supported codec.

How to add folders to your Kinest Library

  1. Tap Add Files & Folders in the empty Library, or open Settings → Video Sources.
  2. Use the native Files picker to select videos and/or folders.
  3. Save your sources, then browse the Library to explore subfolders and video previews.
  4. Return to Kinest to refresh available library contents automatically.

Kinest uses your selected files and folders in their existing locations. If a cloud drive or external device is unavailable, its content may not appear until access is restored.

How to add SRT subtitles on iPad

  1. Open a compatible video in Kinest.
  2. Open the Subtitles & Audio control in the player.
  3. Choose Add Subtitle… and select an SRT file using the Files picker.
  4. Select the imported subtitle track if needed.
  5. Use the subtitle appearance settings to customize text and background styles for externally imported SRT subtitles.

These appearance controls apply to manually imported SRT subtitles, not necessarily to embedded subtitle tracks.
